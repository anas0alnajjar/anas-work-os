# Anas Work OS

نظام PHP/MySQL عربي متعدد المستخدمين لإدارة العلاقات المهنية، فرص العمل، المقابلات، الوثائق، وخطة النشر. كل البيانات والتذكيرات معزولة حسب مالك الحساب.

## الإمكانات الأساسية

- جهات وأشخاص وسجل تواصل قابل للتعديل والحذف مع متابعة تالية واضحة.
- فرص عمل مع CV وCover Letter ووثائق ومقابلات وسجل مراحل وحذف آمن.
- خطة محتوى مفتوحة زمنياً لمنصات LinkedIn وFacebook وInstagram.
- تسجيل حساب، دخول بالبريد أو اسم المستخدم، تأكيد البريد، واستعادة كلمة المرور برمز مشفر أحادي الاستخدام.
- بريد تذكيرات وساعة إرسال ومنطقة زمنية مستقلة لكل مستخدم.
- ملخص يومي للعلاقات والوظائف والمقابلات، وتذكيرات مستقلة لمواعيد النشر.

## المتطلبات

- PHP 8.1 أو أحدث.
- MySQL 5.7 أو MySQL 8 مع InnoDB و`utf8mb4`.
- إضافات `pdo_mysql` و`mbstring` و`fileinfo` و`openssl` و`zip`.
- لا يحتاج Composer أو مكتبات خارجية.

## الملفات الحساسة

الأسرار موجودة فقط في `config.local.php`، وهو مستبعد من Git ومحجوب من Apache وغير موجود داخل حزمة الإنتاج. لا تضع كلمة مرور قاعدة البيانات أو SMTP داخل `config.php` أو أي ملف مرفوع للمستودع.

ابدأ من `config.hostinger.example.php` أو `config.example.php`. يجب أن يتطابق صندوق SMTP المصادق عليه مع `from_email`. بريد SMTP هو المرسل؛ بريد الاستلام يحدده المستخدم من إعدادات حسابه.

## تثبيت جديد

1. أنشئ قاعدة MySQL فارغة وانسخ ملف الإعداد إلى `config.local.php`.
2. اجعل `install_enabled=true` مؤقتاً، افتح `install.php` وأنشئ الحساب الأول.
3. أعد `install_enabled=false` فوراً.
4. سجّل الدخول وشغّل `content_module_setup.php` حتى migration `20260721_004_multi_user_content_ownership`.
5. شغّل `system_update.php` حتى migration `20260721_104_per_user_reminder_hour` وتأكد أن «غير منسوب» يساوي صفراً.
6. اختبر العزل، ثم فعّل `registration_enabled=true` إذا أردت فتح التسجيل.

## ترقية قاعدة موجودة دون فقد البيانات

لا تشغّل `install.php` ولا تستورد `sql/install.sql` فوق قاعدة موجودة.

1. خذ نسخة احتياطية كاملة من قاعدة البيانات وملفات التطبيق.
2. عطّل التسجيل مؤقتاً واحتفظ بـ`config.local.php` و`storage/documents` على الخادم.
3. ارفع حزمة الكود، ثم شغّل `content_module_setup.php` أولاً و`system_update.php` ثانياً.
4. راجع أعداد السجلات والملكية، ثم اختبر بحساب ثانٍ قبل إعادة فتح التسجيل.

التعليمات التفصيلية وأمر Cron موجودة في `HOSTINGER_DEPLOYMENT_AR.md`.

## Cron

شغّل كل ساعة:

```bash
0 * * * * /usr/bin/php /FULL/PATH/cron/send_reminders.php >/dev/null 2>&1
```

فحص آمن دون إرسال أو كتابة سجل:

```bash
php cron/send_reminders.php --dry-run
```

Cron يعالج جميع الحسابات النشطة، يعزل فشل كل مستخدم عن البقية، ويرسل الملخص اليومي في ساعة المستخدم المحلية. التشغيل الساعي مطلوب لتذكيرات النشر المخصصة.

## الحماية

- PDO prepared statements وCSRF وحماية الجلسة بـHttpOnly وSameSite.
- كلمات المرور عبر `password_hash` والرموز مخزنة كـSHA-256 ومحددة الصلاحية.
- ملكية إلزامية للسجلات الجذرية وفحص 404 عند محاولة عبور حساب آخر.
- التحقق من MIME وتوقيع ملفات PDF/Word وتخزينها خارج الوصول المباشر.
- تأكيد نصي للعمليات الهدامة وTransactions عند حذف البيانات المترابطة.
- حجب config وincludes وsql وstorage وcron والوثائق بواسطة `.htaccess`.
